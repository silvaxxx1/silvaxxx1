## 🇸🇩 SAiR — Sudanese AI Research Organization

> **Free. Open-source. Built for engineers who have the curiosity but not the access.**

I founded **[SAiR](https://github.com/SAIR-Org)** to build the AI engineering ecosystem I wished existed when I was starting out: **serious AI education, research, and engineering for Sudanese and African engineers.**

**500+ community · 300+ active learners · 65% completion · 94% interview confidence · 3.2mo avg time-to-offer**

6-module curriculum (Python/DS → ML → DL → GPT-from-scratch → MLOps). Flagship capstone **miniGPT**: configurable 10M–163M param architectures, from-scratch tokenizer/attention/training, DDP + Modal A100 training, fine-tuning modes, web UI, 39 tests.

Student teams now shipping in healthcare diagnostics, crop disease detection, Arabic NLP, LLM apps, and MLOps.
